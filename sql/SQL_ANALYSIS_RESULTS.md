## 核心结论

1. `fav_user` 在 PV 用户中的占比最低：**32.55%**。
2. **23:00** 属于高流量但购买率相对较低的时段。
3. 优先排查低转化类目：`2355072`、`3607361`、`2520377`、`1080785`、`154040`、`2920476`。
4. 加购未购买行为主要集中在 `4756105`、`4145813`、`982926`。
5. 可重点召回 **195,484 名加购未购买用户** 和 **72,211 名高活跃低购买用户**。
